# Security

nanora-unity-mcp lets an AI client run code in your Unity Editor (`execute_csharp`, `execute_menu_item`). The server listens on 127.0.0.1 only and rejects requests from other browser origins. Do not expose its port to a network.

## Reporting a vulnerability

Report privately through [GitHub Security Advisories](https://github.com/nanora-sama/nanora-unity-mcp/security/advisories/new), not in a public issue. Include the version, how to reproduce it, and the impact. Fixes go into the next release and the CHANGELOG.

脆弱性は公開の Issue ではなく、上のリンクから非公開で報告してください。

<CardGrid>
  <Card title="Only Unity" icon="seti:c-sharp">
    The server is C# running in the Editor process. No Node.js, Python, separate server, account or subscription.
  </Card>
  <Card title="Any MCP client" icon="puzzle">
    Streamable HTTP (`/mcp`) and SSE (`/sse`) on the same server. Tested with Claude Code, Codex, Cursor and Claude Desktop.
  </Card>
  <Card title="The AI checks its own work" icon="approve-check">
    Playwright-style selectors, `wait_for_selector`, `assert_ui_state` and `simulate_input` let the AI play the game and verify the result.
  </Card>
  <Card title="Many Editors, no mix-ups" icon="list-format">
    The port is derived from the project path, the client config is written for you, and `/health` names the project.
  </Card>
</CardGrid>

## What an AI built with it

One instruction per level, no human edits afterwards. The AI drove Unity through this server, checked its work with screenshots, input and tests, and fixed what it found.

# サポート / Support

nanora-unity-mcp は個人が開発している無料の OSS です。対応はできる範囲で行います（返答の期限は約束できません）。
nanora-unity-mcp is free, open-source software maintained by one person. Help is best effort; no response time is guaranteed.

## 聞く・報告する / Ask or report

| こんなとき / When | どこへ / Where |
|---|---|
| 動かない・エラーが出る / It does not work | [Issue（不具合の報告 / Bug report）](https://github.com/nanora-sama/nanora-unity-mcp/issues/new/choose) |
| こんなツールが欲しい / Feature idea | [Issue（要望 / Feature request）](https://github.com/nanora-sama/nanora-unity-mcp/issues/new/choose) |
| セキュリティの問題 / Security issue | [SECURITY.md](SECURITY.md)（非公開で / privately） |
| BOOTH でのダウンロード・購入（応援版）の問題 / BOOTH download or purchase | BOOTH のショップへのメッセージ / Message the shop on BOOTH |

不具合の報告には、Unity のバージョン、パッケージの版、AI クライアント、頼んだ文、`mcp_status` の結果を書いてもらえると早く直せます。
For bugs, include the Unity version, package version, client, what you asked, and the `mcp_status` output.

## 対象 / Scope

- 最新の版、Unity 2021.3 LTS 以降。 / The latest release on Unity 2021.3 LTS or later.
- BOOTH の応援版は無料版と中身が同じで、優先サポートは付きません。 / The paid "support" variant on BOOTH has the same contents as the free one and comes with no extra support.
